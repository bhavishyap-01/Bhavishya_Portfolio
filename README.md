# Bhavishya Portfolio

A beginner-friendly student portfolio built with Next.js and React. It is inspired by the dark plum and coral reference design and includes reusable components, project filters, navigation, a learning timeline, and a demo contact form.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Personalize before publishing

- Replace the example projects and student introduction in `app/page.js` with your own details and coursework.
- Update the placeholder contact email in `app/page.js` and your name/title in `app/layout.js`.
- The contact form currently shows an on-page confirmation. Connect a form service or API route to receive submissions.
